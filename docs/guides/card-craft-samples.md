# 精品卡写法（样本）

> 指南，不是契约。字段分工以 [`card-writing-guide.md`](./card-writing-guide.md) **§2.0** 和 [`../architecture/core-design-philosophy.md`](../architecture/core-design-philosophy.md) **§2.1** 为准。
>
> 这里只记结构：什么常驻、什么触发、开场扮演什么角色、状态怎么离开正文。不搬原文，不把样本的规模当成模板。下面每一行是一张标本，不是必选分类，也不是写卡前要先选定的库型。

五张卡都是「场景 + 卡司 + 规则」，不是一个人的小传。差别是这张卡当时怎么写的，不是工具要作者去选的类型。一张卡一行，细节在后面的分节里。

| 卡 | 库的形状 | 开场 |
|---|---|---|
| 《武侠·江湖》 | 约 2014 条。常驻 21 条，其余是薄名录，靠触发词 | 1 条短场面，让玩家立传。整表起点跟在这条后面 |
| 《寻找伪人》 | 81 条。互斥开关包，一组里只开一条 | 主开场是标记「开局」。9 条备选是不同的第一天 |
| 《大凉龙虎传》v3.1 | 621 条。常驻开着 17 条运转，其余按人和地注入 | 主开场是标记「大凉龙虎录」。没有备选 |
| 《隐奸便利店》v2.2.2 | 35 条小卡司。两人的阶段常驻，完整人设靠名字 | 主开场是标记。6 条备选是不同的第一场 |
| 《性瘾妈妈秦抒怀》v1.1 | 24 条小卡司。短的关键信息常驻，人设和阶段靠名字 | 主开场是标记「主页」。3 条备选是不同的第一场 |

## 五张都在做的事

人物、名录、势力不进角色描述。描述或最前面的常驻条目只回答：模型是谁、玩家是谁、不许做什么、核心玩法叫什么、长规则在哪一条。

每轮进上下文的是「怎么运转」，不是百科。武侠把运转收成约二十条常驻（世界怎么转、变量怎么改、境界、战斗、谁在场）。伪人把运转收成硬规则（访客一次只进一个、正文和选项和变量更新分成三截、难度和色度以当前开着的那一条为准）。大凉常驻大约十七条：十三州总纲、境界、熟练度、战力推演、扮演准则、好感、变量格式、思维链、剧情调度、NPC 如何跟着成长、报刊、交通、编年、反全知。名录、功法、药、势力内情、人物、剧情线都靠触发词或按当前局面注入，不常驻。

互斥的设定做成多条条目，只开其中一条。伪人把难度、色度、路线、口味、据点大小各写成一组常驻条目，开局只启用一组里的一条，其余禁用。模型读到的是已经选中的规则，不是一篇「如果是残酷难度就……」。武侠用开场立传达到类似效果：出身不写死在描述里。

整表起点不每轮重发。五张卡的变量初始化都是关着的。武侠把起点接在唯一一条开场后面。伪人用开局脚本写起点，并藏起那条初始化消息。大凉把初始化标成勿开。便利店和秦抒怀的初始化是选择性条目并且禁用。正则再丢掉变量更新。在本工具里：保底写在禁用的世界书初始化，开场正文不写变量块；某条开场和保底不同的路径才记在该条的变量起点。

小卡司走另一条路。便利店和秦抒怀都不铺地图。常驻的是基调、谁此刻必须在场、行为边界、变量格式。完整人设靠名字进来。同一个人「现在走到哪一档」写成一条，用变量挑当前档，不把整条阶梯每轮铺开。便利店里两位主角全程在场，所以阶段常驻、厚人设靠名字。秦抒怀把短的关键信息留在常驻，厚人设和阶段用同一组名字触发，人没被点到，长文不进上下文。

正文、选项、改状态分成三个通道。伪人要求舞台只读一对正文标记中间的字，思考放在标记外，选项在正文后，变量更新在选项后。武侠要求档位和判定留在隐藏块，正文只写因由。正则负责不把这些块发回模型，也不铺在读者脸上。

长规则只写一次。每轮提醒很短，并点名那几条常驻条目，不把长规则再抄进系统提示或作者注释。作者注释写怎么装、这一版改了什么，不写设定本身。

## 《武侠·江湖》

场景契约放在角色描述，大约三百字，三件事说完：模型是这方江湖并演每一个关键人物；玩家是初入江湖的人，模型不替他决定、不替他说话；核心是经脉穴位，细节指到常驻规则。文风和两种要躲开的滑坡（把具体写成标价、把来历写成残破）另写，不和身份契约搅在一起。情景只留年代和一句「开局由玩家的名帖决定」。

约两千条里，常驻的二十一条没有触发词，位置在角色定义之后。其余近两千条（功法、药、兵器、风闻）中位大约三百字、平均约六个关键词，被点到名才进来。

开场正文大约两百字，只摆时代和天气，然后让玩家写名帖。完整起点跟在这条开场后面。世界书里的初始化关着，避免每轮再灌一遍。

能拿走的是这个分法。两千条名录、穴位面板和五个脚本是这张卡自己的产品，不是起步尺寸。

## 《寻找伪人》

角色描述、性格、情景、系统提示、历史后指令都是空的。世界和本局开关放在世界书，而且多条用 `before_char`，插在角色定义之前。在本工具里不要学「描述留空」：场景契约仍写在角色描述。开关包仍做成世界书条目，由开局选择启用哪一条。

常驻并且开着的大约三十一条，是本局真的会读到的规则：生态、据点、访客铁律、十四条时间线、标准难度、均衡色度、主线、对等口味、变量格式、演出协议。同一组里的其他档（轻松 / 残酷、淡 / 浓、其他路线、其他口味、更大的据点）是常驻但禁用。触发词条目约二十八条，主要是势力、派系和 Boss，点到名才进来。条目比武侠少，单条更厚（中位约一千二百字）。

主开场只有「开局」两个字，用来唤起配置面板。九条备选才是九种第一天：同一间 302，身份和阵营不同。在本工具里，这九条就是备选开场；主开场要么写成默认的那一天，要么写成和伪人一样的「先配置再开幕」，但配置说明不要塞进正文。

访客铁律是一条总闸：一次只处理一张脸，当天配额必须走完，正文改了状态就必须改变量。难度、色度、路线只决定「哪一条包开着」，不在铁律里再写九种分支。演出边界规定思考、正文、选项、变量更新的顺序，避免模型把检查清单写进读者看见的字。

## 《大凉龙虎传》

角色描述、性格、情景、系统提示、历史后指令、作者注释都是空的。主开场只有「大凉龙虎录」六个字，没有备选。世界在世界书里。在本工具里仍然不要学「描述留空」：场景契约写在角色描述。这张卡用一条常驻的「剧情与扮演核心准则」顶了契约的位置，总纲、编年、交通是另外几条短常驻。

库是名册，不是开关包，也不是两千条薄名录。大约六百二十一条里，常驻开着的十七条是运转。人物详情是短条，大约三四百字，触发词是名字。同一个人的说话方式另写一条「性格调色盘」，大约两千字，多数不挂触发词，等人上场再注入。势力详情、剧情线各是一条长文、一个触发词。十三州先有短的区域条和人名表，人没到那个州，详情不进上下文。武学、秘境、盛会同样靠名字进来。界面源文件（任务栏、突破、战力推演）和设定分开，挂在界面自己的触发词上。

六条「叶调度」（区域、境界、剧情线、调色盘、势力、规则）是常驻但关着的，旁边有脚本「注入预算管理」。调度说明本身不每轮占上下文，由预算按当前局面去挑叶子。这是这张卡自己的产品。能拿走的是预算这件事：当前州、当前人、当前剧情线才配得上长文。

另有一条常驻的「反全知与身份隐匿」。写过人物条，不代表路上的人知道这条里的秘密。模型不能因为世界书里有，就在正文里全知道。

NPC 好感和境界同步成长是常驻规则：关系会变，别人的境界也会跟着主角长，不把人物写成第一次见面就永远停在那一档。

## 《隐奸便利店》

角色描述、性格、情景、系统提示、历史后指令都是空的。作者注释只有署名和出处。主开场是标记「emo的lsp」，正则把它换成开场面板。六条备选才是六场已经发生的第一幕：店里、客厅、探病、夜里的班、夜里的家。同一家人，入口不同。在本工具里仍然不要学「描述留空」：场景契约写在角色描述。这张卡用常驻的创作指令、语气和基调顶了契约的位置。作者注释仍写怎么装、这一版改了什么，不要只留一行署名。

三十五条里，常驻开着的大约二十五条是运转：两人各自的阶段、玩家人设、店和家和学校、语气、场景系统、变量格式、角色列表。角色列表写明谁全程在场、谁被点到名才出现，并和条目的常驻或触发一致。两位主角的完整人设是厚条，放在角色定义之前，触发词是名字和身份（太太、母亲、女儿）。配角同样靠名字。阶段条是常驻，里面按堕落值分档，只呈现当前档的姿态和能看见的表现，不把下一档写成已经发生，也不把阶段写成分数奖励。阶段条上虽然挂了触发词，常驻条目的触发词不起门禁作用。

可选块夹在一对很短的开始和结束标记中间。文风和选项默认开着，日记小剧场和手机小剧场默认关着。插图三条常驻但关着，正则只负责把正文里的图标记画出来。空着的可选位不必预留成空条目。

## 《性瘾妈妈秦抒怀》

壳层同样是空的，作者注释同样只有署名和出处。主开场是标记「主页」。三条备选是三场第一幕：夜里的客厅、午后的图书馆、暗着的卧室。场景契约在本工具里仍写角色描述。这张卡用一条放在角色定义之前的叙事基调顶了这个位置，大约五百字，只定基调和双层气氛。

二十四条。常驻的是基调、玩家、公寓、刑警支队、发作时段、行为禁区、两人各一条短的关键信息、角色列表、变量格式、日常选项。每晚固定时段的发作是一条常驻机制，写前兆、外在表现和这个人会怎么收束，描写参考留在这条里，不进角色描述。行为禁区也是一条常驻：这个人绝对不会说的话、不会做的驱逐和动手。选项规定正文结尾给八条，从玩家视角、祈使句、包在选项标记里。

人分成三层。关键信息是短条，常驻，保证人没被点名时模型仍知道她是谁、眼下卡在哪。完整人设是厚条，放在角色定义之前，触发词是名字和身份。阶段是另一条厚条，触发词和人设相同，所以人上场时人设和当前档一起进来，人没上场时两份长文都不在。阶段按心理防线分档，靠近下一档只写动摇，不把下一档写成已经跨过。特殊事件收在一条常驻里，用变量挑出当前满足条件的那一件，不把所有事件每轮铺开。学校和犯罪组织靠触发词。家里和支队常驻，因为人经常在那里。

两条「可选内容」是空的占位，选择性、关着。这是这张卡自己的产品。可选玩法要写就写成能开关的实条，像便利店那样夹在标记里，不要留空条目占着。

## 落到本工具

| 样本里的东西 | 写在 |
|---|---|
| 模型是谁、玩家是谁、不许做什么、核心玩法叫什么 | 角色描述（场景契约） |
| 文风和明确禁止的滑坡 | 场景契约的短段，或一条常驻世界书 |
| 年代、地点、开局由谁决定 | 情景，一两句 |
| 怎么运转、怎么改变量、谁在场、战斗或访客铁律 | 常驻世界书，少量 |
| 功法、药、势力内情、Boss、图鉴 | 世界书，带触发词，不常驻 |
| 人物是谁、哪一派、什么境界 | 世界书短条，触发词是名字 |
| 这个人怎么说话 | 另一条，人上场才注入，不写进短条，也不常驻 |
| 这个人现在走到哪一档 | 一条阶段。用变量挑当前档，只写这一档的姿态 |
| 人没被点名也必须知道的短事实 | 常驻短条（关键信息） |
| 这个人绝对不会做的事 | 一条常驻的行为禁区 |
| 可选玩法（文风、选项、小剧场） | 夹在一对标记之间，默认可以关。不留空条目占位 |
| 地图 | 每地一条短索引；详情和剧情线另条，一个触发词 |
| 模型不能因为写过就全知道 | 一条常驻的反全知 |
| 难度、路线、口味这类互斥档 | 一组世界书，开局只启用一条 |
| 第一天的不同身份 | 主开场 + 备选开场。每条只写这一天已经发生的事 |
| 整表起点 | 禁用的世界书初始化。开场正文不写变量块 |
| 某条开场和保底不同的路径 | 该条开场的变量起点 |
| 怎么安装脚本、这一版改了什么 | 作者注释 |

检查一张卡时看这四句：角色描述能不能在不看世界书的情况下说清契约；常驻条目是不是少到能说出名；点一个名录里的名字才该出现的内容有没有触发词；开场第一屏是不是场面，而不是设定说明书。

再收不同路数的卡时，按同一张表补一行，并写明哪一条是这张卡自己的产品、哪一条能进通则。通则稳定之后才改 AI 引擎的生成提示词。
